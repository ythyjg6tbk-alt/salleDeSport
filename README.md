# Le Domaine d'Asgaard — Salle de musculation à Aubusson (Creuse)

Site de pré-inscription pour l'ouverture du Domaine d'Asgaard (5 rue de l'Abreuvoir, 23200 Aubusson), salle de musculation indépendante. Site multi-pages statique (HTML + `style.css` partagé, sans dépendance JS hors polices Google Fonts ; le menu mobile est en CSS pur).

Pages : `index.html` (Accueil), `histoire.html` (Notre histoire), `bar.html` (Le bar), `abonnements.html` (offre Fondateur + abonnements classiques), `faq.html`, `contact.html`.

Contenu : offre de lancement Fondateur (240€ TTC / 12 mois, 50 places, seule offre actionnable avant l'ouverture), abonnements classiques prévus à l'ouverture (Mensuel 24,99€/mois, Pass Day 9,99€, Duo 45€/mois), présentation de la salle, comptoir, partenaires, FAQ et contact.
